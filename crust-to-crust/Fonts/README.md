# HUD font

`Tiny5.ttf` is the upright Tiny5 variable font from the official Google Fonts
repository, downloaded on 2026-10-15:
https://github.com/google/fonts/tree/main/ofl/tiny5

Original upstream: https://github.com/Gissio/font_Tiny5

Redistributed under SIL Open Font License 1.1; the full license and copyright
notice are in `Tiny5-OFL.txt`. Font outlines have not been modified. The gameplay
telemetry panel disables antialiasing and subpixel positioning at runtime.

Tiny5 is applied only to telemetry readouts; the workshop and other screens
retain their existing fonts.
