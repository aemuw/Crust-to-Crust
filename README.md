# Crust to Crust

Двовимірна аркадна гра про падіння крізь планету. Гравець керує кам’яною фігурою,
оминає перешкоди й збирає монети в темному підземному тунелі. На глибині 20 000 метрів
починається проходження ядра, а після 40 000 метрів персонаж вилітає на протилежному
боці планети та розпочинає наступне коло зі збільшеною швидкістю.

## Ігрові можливості

- Чотири зони з різним оформленням і небезпеками: базальтовий розлом, кристалічний
  пояс, магмові тріщини та серце планети.
- Спрямований ліхтар із тінями й обмеженим зарядом. Батарейки поповнюють запас енергії.
- Рухомі перешкоди, настінні стрільці, обвали та локальні події з попередженнями.
- Нагрівання й горіння поблизу ядра. Кріотріщини охолоджують персонажа та тимчасово
  захищають його від жару.
- Майстерня з покращеннями спорядження, 27 піксельними скінами для дев’яти форм
  і косметичними слідами.
- Збереження рекордів, монет, покупок і налаштувань між запусками.
- Вибір seed для повторного проходження маршруту, навчання та підтримка геймпада.

## Вимоги

- **Godot 4.7.2 .NET** — редактор із підтримкою C#.
- **.NET SDK 8** або новіший SDK із підтримкою цільової платформи .NET 8.
- Графічний адаптер із підтримкою OpenGL 3.3. Проєкт використовує GL Compatibility.

## Запуск

1. Завантажте репозиторій або клонуйте гілку:

   ```bash
   git clone --branch release --single-branch https://github.com/aemuw/Crust-to-Crust.git
   ```

2. У редакторі Godot .NET імпортуйте файл `crust-to-crust/project.godot`.
3. Дочекайтеся імпорту ресурсів і зберіть C#-проєкт кнопкою **Build**.
4. Натисніть **F5**, щоб запустити гру.

Зібрати C#-проєкт також можна з кореня репозиторію:

```bash
dotnet build crust-to-crust/Crust-to-Crust.csproj
```

## Керування

| Дія | Клавіатура та миша | Геймпад |
| --- | --- | --- |
| Рух ліворуч / праворуч | A / D або стрілки | Лівий стік або хрестовина |

## Структура проєкту

Основний проєкт розташований у папці `crust-to-crust/`:

| Шлях | Вміст |
| --- | --- |
| `Scenes/` | Сцени рівня, персонажа, оточення та ігрових об’єктів |
| `Scripts/` | Ігрова логіка на C# |
| `Shaders/` | Шейдери освітлення, вогню, газу та оточення |
| `Textures/` | Графіка світу, перешкод, предметів і скінів |
| `Audio/` | Музика, фонові звуки та звукові ефекти |
| `Fonts/` | Шрифти та їхні ліцензії |
| `project.godot` | Налаштування та точка імпорту проєкту |

Гру створено на **Godot Engine** з використанням **C#**, **.NET 8** і шейдерів Godot.
